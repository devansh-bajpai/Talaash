# 🕵️‍♂️ Detective Case Management & Similarity Search System

A full-stack platform designed for **detectives and investigators** to manage cases, run AI-powered similarity searches, and streamline investigation workflows.  
Built using **Next.js, Express, MongoDB, and Tailwind CSS**.

## 🛠️ Tech Stack

### **Frontend**
- Next.js (App Router)
- TypeScript  
- Tailwind CSS  
- Axios  
- JWT 

### **Backend**
- Node.js  
- Express.js  
- JWT Authentication  
- Bcrypt for password hashing  

### **Database**
- MongoDB (Mongoose)

### **Other Tools**
- OpenAI / Embeddings (Similarity Search)  
- Socket.IO (for future real-time features)

---

## 🚀 Features

### 🔐 Authentication System
- Secure login / signup  
- JWT-based authentication  
- Role-based access (Detective / Admin)  
- Protected routes  

---

### 🗂️ Case Management
- Add new cases with title, description, and status  (form to be added)
- Update case progress (Pending → Running → Completed)  
- View all assigned cases  
- Case timeline & details page  

---

### 🧠 Similarity Search Engine
- AI-powered comparison of case descriptions  
- Helps find similar past cases  
- Generates relevance score  
- Useful for pattern recognition & linking crimes  

---

### 📊 Dashboard & Analytics
- Quick summary of active cases  
- Similarity search history  
- Crime statistics (if enabled)  

---

### 📁 Data Management
- Secure MongoDB storage  
- User profiles  
- Search logs  
- Case and similarity metadata
